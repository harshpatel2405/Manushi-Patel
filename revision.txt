Printf --> print output on screen / console 
scanf --> take input 
format specifiers -> %d , %c, %f
datatype --> int , float , char
escape sequence -> \n , \t
operators 
    1. arithmetic operators + - * / %
    2. relational operators < > <= >= == !=
    3. Logical operator 
        and -> && -> when both conditions are true 
        or  -> || -> when any of the condition is true 
        not -> ! -> changes true to false or false to true
        
conditionals 
    if_else 
        if checks the condition 
            and if the condition is true , then performs logic 
        else 
            execute the remaining part
